# Changelog

All notable changes to the "antigravity-flush" extension will be documented in this file.

## [1.1.0] - 2026-01-08

### Added
- MCP Warning: Warns if >20 MCP commands are registered
- Auto-Reload: Option to reload window after flush
- Documentation: Clarified Opus model crash fixes

## [1.0.2] - 2026-01-08

### Changed
- Prepared for manual installation build

## [1.0.0] - 2026-01-07

### Added
- Initial release
- Status bar "Flush Context" button
- Keyboard shortcut `Ctrl+Shift+Alt+F`
- Commands: Flush All, Flush Current
- Confirmation dialog before clearing
- Clears conversations, context_state, and brain directories
